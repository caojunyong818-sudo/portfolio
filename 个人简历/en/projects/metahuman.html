Overview

This project explores a workflow from text commands to MetaHuman animation: matching reference videos, processing motion data and generating playable animation assets. The plugin runs in the UE5 Editor and connects retrieval, processing and asset creation into a continuous sequence.

From commands to animation assets

Commands such as walk and run retrieve corresponding reference videos and feed the subsequent motion-processing and animation-generation stages. The project connects existing tools so a textual request can enter a concrete animation workflow.

My contribution

From May to June 2026, I developed the editor interface in C++ and Slate and used Python to integrate Capture Manager, MetaHuman Performance and Body Tracking. Development included troubleshooting skeletal retargeting, cached animation and missing bone tracks.
