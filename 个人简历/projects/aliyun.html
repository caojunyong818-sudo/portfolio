项目简介

“问境工坊”是一项基于阿里云通义能力的 AI 创作工作台设计实践，面向内容创作者组织对话、图像生成与作品浏览等使用场景。项目从功能结构、界面布局推进到网页原型与接口接入，探索如何让创作需求更顺畅地转化为具体操作。

围绕创作任务组织界面

页面结构涵盖产品介绍、创作入口、对话与作品画廊。通过任务卡片和功能分区帮助用户识别可用能力，再进入具体的创作页面；画廊则提供浏览与回看内容的入口。

视觉探索包含深色工作台、浅色任务界面和蓝紫色品牌展示等方案。下方图像记录的是不同页面与阶段的设计表达。

我的工作：连接界面与功能

我负责 UI 策划与程序实现，使用 Figma 设计界面与交互流程，梳理功能层级、页面切换和任务组织，并以 JavaScript 与 Python 构建网页原型、接入通义相关 API。页面涵盖登录、欢迎、产品介绍、灵感画廊与主工作台，用于检验从输入需求到获取返回结果的流程。

项目以设计与功能原型为展示范围，重点体现创作工作流的组织和接口整合。
