# 作品集上线说明

这个目录是整理后的 GitHub Pages 发布包。

## 推荐上线方式

1. 在 GitHub 新建一个公开仓库，例如 `portfolio`.
2. 将本目录 `portfolio-publish` 内的所有文件上传到仓库根目录。
3. 进入仓库 `Settings -> Pages`。
4. `Build and deployment` 选择 `Deploy from a branch`。
5. 分支选择 `main`，目录选择 `/root`，保存。
6. 等待 GitHub Pages 部署完成，访问 `https://你的用户名.github.io/portfolio/`。

## 注意

- 已删除首页个人简介里的视频框架。
- 发布包没有包含超过 100MB 的源视频文件，避免 GitHub 上传失败。
- 阿里云通义千问网页展示入口已改为线上链接。
